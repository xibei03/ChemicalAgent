# 转化反应器的建模要点

转化反应器按给定的转化率直接算出口组成，不需要动力学，也不需要平衡数据。

- **转化率针对基准组分。** 每个反应写明基准组分（反应物之一）和转化率；转化率按进料里基准组分的量算。
  `conversion` 照原文写：“转化率 X%”写 X、单位 `%`；原文写的是小数，就写小数、单位 `fraction`。
- **同一个基准组分有几个反应时，它们是并行的**，各自的转化率都相对于进料，总和不能超过 100%。
- **用户给的是收率或选择性，不是转化率时**：由收率或选择性得到每个反应的转化率要做算术，你不做。把原文
  的数值照抄进 `ambiguities`，该反应的 `conversion` 写 `null`，并在 `missing` 里列出（`field` 选
  `conversion`）。
- **串联的反应不支持**：一个反应的产物又是另一个反应的反应物时，在 `ambiguities` 里说明，不要用并行
  的写法去近似。
- **产物是几种组分而用户没有给出它们之间的比例时**（比如几种异构体），采用反应温度下的热力学平衡分布：
  把这个产物写进 `split_products`，各组分带配比；在 `assumptions`（`field` 选 `reactions`）里写明配比的取值
  和依据。用户给了比例的，按用户的，不算假设。
- **热模式**：规定了出口温度就写进工况；没有规定出口温度和热负荷时，出口温度是计算结果，工况的两个量
  写 `null`。
- **动力学参数、设备尺寸用不上**：不需要写进 TaskSpec。用户给了，在 `ambiguities` 里提一句即可。
