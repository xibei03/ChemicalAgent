# 选型规则

这是反应器选型的依据，来自需求文档的选择逻辑（§8）和补充信息（§9）。核心是：**没有哪一类反应器绝对正确，只有合不合适**。下面是判断“合不合适”的顺序和理由。

## 各类反应器适合什么

| 类型 | 它做什么 | 用它需要什么 | 适合的情况 |
|---|---|---|---|
| Conversion | 按给定的转化率（或由收率、选择性换算出的转化率）直接算出口组成 | 转化率、收率或选择性的数值 | 用户已经知道工艺指标，不需要反应器自己算出反应进行到什么程度 |
| Equilibrium | 按化学平衡算反应终点 | 反应已经明确；平衡常数 Ka（或 Keq）由用户给，没给时由 Gibbs 自由能算 | 可逆反应，反应终点由热力学平衡决定 |
| Gibbs | 总自由能最小时的产物分布 | 只要进料组成、温度、压力；不需要写反应式 | 产物分布未知、反应机理复杂、温度很高的体系 |
| PFR | 沿管长积分速率方程 | 动力学参数（速率常数、活化能、级数等），还需要尺寸 | 有动力学的管式反应器；有动力学的气相反应 |
| CSTR | 全混流，出口浓度即釜内浓度 | 动力学参数，还需要体积 | 有动力学的釜式反应器；有动力学的液相反应 |

## 选择的顺序

按下面的顺序，取第一条适用的：

1. **用户点名了反应器模型，并且它需要的输入都有**：采纳。点名的类型缺必要输入时，说明缺什么，继续往下判断。
2. **给出了动力学参数**：选动力学反应器。
   - 说明了管式，选 PFR；说明了釜式，选 CSTR。
   - 没有说明设备形式时，看反应物的相态：气相选 PFR，液相选 CSTR。
   - 设备形式和相态都定不了时，凭工程判断在两者之间选一个，并说明理由。
   - **聚合反应不适用这一条**：聚合的动力学特殊（链增长、链终止、分子量分布），按本节的后面几条判断。
   - 缺设备尺寸不影响选型：仍然选动力学反应器，只是要把尺寸列为缺失的信息。
3. **没有动力学参数，但给出了转化率、收率或选择性的数值**：选 Conversion。
4. **黑箱类体系**：选 Gibbs。气化、燃烧、裂解这类过程温度高、不靠催化、机理复杂，实际的产物分布取决于热力学平衡或停留时间，不是用户写出的某一个反应式能描述的。所以即使用户写出了一个主反应式，也选 Gibbs。
5. **反应已经明确**（写出了全部反应式，或者点明了一个确定的反应，没有要求考虑未写出的副反应）：选 Equilibrium，由平衡常数或 Gibbs 自由能确定反应终点。
6. **以上都不满足**：选 Gibbs。它不需要反应式，是信息最少时最稳妥的选择。

## 补充的工艺知识

- **多个可逆反应、反应式都已写出、受热力学平衡控制**的体系，用 Equilibrium：它按给定的反应求平衡，反应数多不要紧，关键是反应都写明了。
- **可逆反应不等于必须用 Equilibrium。** 反应受平衡限制，但用户直接给出了要达到的转化率并要按它计算时，选 Conversion；这时可以提醒检查该转化率不超过平衡极限。
- **Equilibrium 与 Gibbs 的分界**在于反应是否列全：写全了用 Equilibrium；没写全、写不全或者明说产物未知，用 Gibbs。
- **高温不是选 Gibbs 的充分条件。** 高温下的催化反应，反应式明确且可逆，仍然是 Equilibrium；Gibbs 针对的是反应机理复杂、产物难以预料的体系。
- **管式、釜式描述的是设备形式。** 有动力学参数时，它决定 PFR 还是 CSTR；没有动力学参数时，它不影响选型，回到第 3 条以后。
